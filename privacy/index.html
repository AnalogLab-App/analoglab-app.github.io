Политика конфиденциальности Analog.Lab (веб-версия)

Analog.Lab — таймер проявки плёнки. Веб-версия — это сайт, который открывается в браузере и может быть установлен как приложение. Он ничего о вас не собирает.

Ваши данные

  • Пресеты, бачки, журнал, заметки и настройки хранятся только в этом браузере на этом устройстве (хранилище IndexedDB) и никуда не отправляются — ни разработчику, ни кому-то ещё.
  • Удалить их можно в приложении: «Настройки» → «Удалить все данные», или очисткой данных сайта в браузере.
  • Резервная копия — файл, который вы сами сохраняете и сами решаете, куда положить или кому отправить.

Чего сайт не делает

  • Нет аналитики, счётчиков, трекеров и рекламы.
  • Нет cookie.
  • Нет регистрации и входа.
  • Сайт не обращается к другим серверам: шрифты, значки и код загружаются только с этого же адреса. После первого открытия он работает без интернета.
  • Голос сигналов — синтез речи вашего браузера и системы. Как он устроен, решает производитель браузера и системы.

Где размещён сайт

Сайт размещён на GitHub Pages. Как у любого сервера, у GitHub при открытии сайта могут сохраняться технические данные запроса, например IP-адрес и сведения о браузере. Разработчик Analog.Lab к ним доступа не имеет. Подробнее — в заявлении GitHub о конфиденциальности.

Ссылки

Ссылки «Поддержать автора», Google Play и RuStore открывают внешние сайты в браузере. На них действуют их собственные правила.

Analog.Lab privacy policy (web version)

Analog.Lab is a film development timer. The web version is a site that opens in a browser and can be installed as an app. It collects nothing about you.

Your data

  • Presets, tanks, the log, notes and settings are stored only in this browser on this device (IndexedDB storage) and are never sent anywhere — not to the developer, not to anyone else.
  • You can delete them in the app (Settings → Delete all data) or by clearing the site data in your browser.
  • A backup is a file you save yourself, and you decide where to keep it or whom to send it to.

What the site doesn’t do

  • No analytics, counters, trackers or advertising.
  • No cookies.
  • No sign-up or sign-in.
  • The site makes no requests to other servers: fonts, icons and code load only from this same address. After the first visit it works offline.
  • Voice prompts use the text-to-speech of your browser and system; how it works is up to their makers.

Where the site is hosted

The site is hosted on GitHub Pages. Like any server, GitHub may keep technical request data when the site is opened, such as the IP address and browser details. The Analog.Lab developer has no access to it. See the GitHub General Privacy Statement.

Links
